# Supply Chain Risk Desk

A clean red, black, and white Supply Chain Risk Management starter website.

## What is included

- Home page
- Blog page
- Risk dashboard page
- Resource library
- Case studies page
- Mobile responsive design
- Starter GitHub Actions workflow placeholder for future daily updates

## How to publish free with GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository named `scrm-risk-desk`.
3. Upload all files from this folder.
4. Go to Settings > Pages.
5. Under "Build and deployment", choose "Deploy from a branch."
6. Select the `main` branch and `/root`.
7. Save.
8. GitHub will give you a public website link.

## Daily dashboard updates

The current dashboard is a clean starter layout. The next step is connecting the feed to curated RSS/public data sources.

Recommended source categories:

- CISA cybersecurity advisories
- NIST SCRM/cyber updates
- OFAC sanctions updates
- BIS export control updates
- USTR trade updates
- NOAA/NHC disaster feeds
- Google News RSS searches for trade, shipping, cyber SCRM, and supply chain disruption

Do not scrape every website on the internet. Use curated sources so the dashboard stays professional and useful.
